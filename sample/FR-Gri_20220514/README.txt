Be aware that the examples in this folder run with the new version.
However, new features such as the partitioning of ET, are not shown here.
For this just please use the main README.md file and read the documentation of the process() function.
Also, in case of RAM overflow for run_from_eddypro() consider using the argument memory_eff in the transform_kwargs (see main README.md).
